# CationMedia

Windows-просмотрщик медиафайлов с редактированием на Electron, Vite и Three.js. Поддерживаются 3D-файлы, изображения, аудио и видео — см. [план изображений](docs/image-viewer-plan.md), [аудиоредактор](docs/audio.md), [медиаредакторы](docs/media-editors.md) и [единый UI](docs/media-ui.md). Интерфейс на английском. Без React, сервера приложений, аналитики и облачных загрузок.

## Запуск

Требуется Node.js 22.12+.

```powershell
npm ci
npm run dev
```

Запуск готовой сборки:

```powershell
npm run build
npm start
```

## Windows

```powershell
npm run dist:win
```

Результат: `release/CationMedia Setup <версия>.exe`. Установщик NSIS позволяет выбрать каталог, создаёт ярлык и регистрирует поддерживаемые расширения. Также доступна распакованная версия `release/win-unpacked/CationMedia.exe`.

После установки выберите CationMedia через **Open with → Choose another app → Always**, либо через меню **Settings → Default apps…**. Приложение открывает системные настройки; защищённый выбор приложения по умолчанию остаётся за пользователем Windows. Сам просмотрщик не меняет текущие ассоциации принудительно.

Установщик регистрирует `.jpg`, `.jpeg`, `.tif`, `.tiff`, `.png`, `.gif`, `.webp` и `.bmp` в **Open with** и **Default apps**; выбор приложения по умолчанию для каждого расширения делается в Windows отдельно. Регистр имени расширения не влияет на открытие, в том числе для `.JPEG`. Изменение регистрации требует пересборки и переустановки.

При обновлении сохраняйте область и путь существующей установки. Проверяйте путь работающего процесса и команды файловых ассоциаций: установка новой копии с `/currentuser` рядом со старой в Program Files не обновляет старый EXE. Кроме того, уже запущенная старая копия может принимать файлы через single-instance lock. Установку в `C:\Program Files\CationMedia` обновляйте установщиком с `/allusers` и обычным запросом UAC. Приёмка включает открытие реального файла, проверку пути/версии процесса и ярлыка, а не только прямой запуск тестируемого EXE.

В **Default apps** найдите CationMedia по имени и назначьте его для нужных расширений. Для установленной на весь компьютер версии страницу приложения можно открыть адресом `ms-settings:defaultapps?registeredAppMachine=CationMedia`. Если приложения нет в списке, в Проводнике используйте **Open with → Choose another app → Choose an app on your PC**, укажите установленный `CationMedia.exe` и выберите **Always**. Пункт меню приложения открывает системные настройки.

`build/installer.nsh` дополнительно регистрирует `RegisteredApplications` и `Capabilities`, чтобы приложение появлялось в поиске Windows по имени. Изменение вступает в силу после сборки и установки обновлённого пакета; старый установленный пакет от правки исходников не меняется. [Документация Microsoft](https://learn.microsoft.com/en-us/windows/win32/shell/default-programs).

`.blend` исключён из файловых ассоциаций CationMedia: установщик удаляет собственную старую регистрацию и восстанавливает зарегистрированный тип Blender, если прежняя версия назначила CationMedia. Открытие BLEND внутри просмотрщика и через drag-and-drop сохраняется. Значки зарегистрированных типов используют отдельный ICO с версией в имени; после установки Windows получает уведомление об обновлении ассоциаций.

Сборка не содержит сертификата подписи кода. Для публичной дистрибуции настройте сертификат electron-builder через переменные окружения. Секреты в проект не добавлять.

## Стартовый экран

При запуске без файла открывается экран с кнопками **Sounds**, **Viewer 3D**, **Video** и **Images**. Кнопки вызывают выбор файлов соответствующего типа. **File → Home** возвращает на стартовый экран; демо доступно только через **File → Load 3D demo**. При запуске с файлом сразу открывается соответствующий документ.

## Изображения

Каждое новое изображение открывается полноэкранно на тёмном фоне. Наведение у верхней кромки показывает ленту изображений из той же папки. Двойной клик переводит в оконный редактор с локальным браузером файлов; повторный двойной клик возвращает полноэкранный режим без сброса правок. В редакторе доступны crop, отражение, поворот, resize, цветовые коррекции, удаление фона по цвету и двум цветам нарисованной сетки, trim прозрачных полей и диагностическая маска альфы. Атлас собирается автоматически либо сеткой с ограничениями размеров и сохраняется вместе с JSON координат.

**Save as / Convert** создаёт новый файл и не перезаписывает исходник или существующий результат. Экспортируются PNG, JPEG, WebP, BMP, TIFF и статический GIF; PNG/WebP/TIFF сохраняют альфу, JPEG/BMP используют выбранный матовый цвет. Исходный анимированный GIF просматривается с анимацией, но редактирование и экспорт берут только первый кадр; статический GIF сохраняет только бинарную прозрачность. TIFF для просмотра декодируется локальным FFmpeg. Локальный браузер папок и запись доступны в Electron; в браузерном режиме доступен просмотр выбранного файла. Подробности и границы доступа описаны в [плане модуля](docs/image-viewer-plan.md).

Перетащить поддерживаемый файл можно на любую область содержимого окна: стартовый экран, кнопку, поле, волну, viewport или боковую панель. Режим выбирается по файлу независимо от места drop; модель и её текстуры можно передать вместе. Проверка: `node tests/home-smoke.mjs` после сборки, `VIEWER_EXECUTABLE` — для установленного приложения.

## Возможности

- Open file, Ctrl+O, drag-and-drop в любую часть окна, открытие из Проводника и передача файла уже запущенному экземпляру.
- GLB/glTF, FBX, OBJ с MTL, STL, PLY, DAE, 3DS, BLEND.
- Materials, Solid, Wireframe и Normals (цветовая визуализация нормалей).
- Орбита левой кнопкой, панорамирование правой, масштабирование колесом; F — кадрировать модель.
- Десятичная клавиша нумпада (точка/запятая в EN/RU) — центрировать выбранный объект и подобрать масштаб по его размерам, сохранив текущий ракурс. Работает в перспективе и ортографии; без выделения ничего не меняет.
- Правый клик по мешу в viewport или дереве: **Shade Smooth**, **Shade Auto Smooth (30°)**, **Shade Flat**, **Convert To** и **Restore Imported Shading**. Правое перетаскивание остаётся панорамированием; правый клик на пустом месте viewport или дерева снимает выделение и открывает меню для всей модели, включая скрытые меши. Convert To в этом меню сохраняет всю модель. На меше команды применяются к выбранному объекту, исходный файл не перезаписывается.
- Дерево сцены с поиском и переключателями видимости; двойной щелчок кадрирует объект.
- Клик по мешу в viewport выделяет его в дереве и рамкой в сцене. Под мешем указаны материалы; статистика сверху слева показывает вершины и треугольники выбранного объекта, а без выделения — всей модели. Вершины считаются по буферу геометрии, без объединения совпадающих позиций.
- Сферические кнопки справа сверху: Normals, Wireframe, Solid, Materials. Подписи доступны по наведению.
- Границы боковых панелей перетаскиваются; размеры сохраняются. После фокуса на границе доступны стрелки и Home для сброса размера.
- Анимации в правой панели: выбор клипа, Play/Pause, перемотка, скорость; пробел переключает воспроизведение.
- Настройка фона, экспозиции, сетки, автоматического вращения. Клавиши 4/6 — поворот на 15°, 5 — перспектива/ортография, 7 — сверху, 1 — спереди, 3 — справа. Работают верхний ряд цифр и NumPad.
- Локальные Draco/KTX2/Meshopt-декодеры; интернет для просмотра не требуется.
- Рендер по изменениям; при анимации или вращении — непрерывно. Геометрии, текстуры и материалы освобождаются при смене модели.

## Blender

Нужен установленный Blender (проверено с 5.1). Приложение ищет его в PATH и стандартном каталоге Blender Foundation. Можно указать `blender.exe` через **Settings → Set Blender path…**.

`.blend` открывается фоновым Blender с `--factory-startup --disable-autoexec`, экспортируется во временный GLB и загружается Three.js. Исходный файл не изменяется. На конвертацию отведено 120 секунд; временные файлы удаляются при выходе. Blender не включён в установщик.

Передаются объекты и материалы, поддерживаемые glTF-экспортом Blender. Процедурные материалы, композиция, специфические эффекты Blender и симуляции не обязаны выглядеть как в Cycles/Eevee. Сначала запекайте такие данные в текстуры/анимации, если необходим точный результат.

## Ресурсы модели

Поддерживается связка IMPION **`model.glb`/`model.gltf` + `model.json` + изображения**. Desktop автоматически находит одноимённый JSON рядом с моделью; в браузере перетащите модель, JSON и текстуры вместе. Из `objects[].materials` и `materials` восстанавливаются назначения, базовый цвет, прозрачность, стороны и основные параметры Standard/Lambert/Phong/Basic. Из `params` и `impion.parameters` читаются ссылки на карты. Идентификатор текстуры сопоставляется с именем файла и форматом из `textures`; изображения ищутся рядом и в `textures`/`maps`.

Имена объектов сопоставляются точно, затем по уникальному имени без пунктуации Blender. Отсутствующие или повреждённые изображения перечисляются в предупреждении; вместо них не назначаются посторонние атласы. Без JSON обычная загрузка GLB/glTF сохраняется. Произвольные узлы Blender и пользовательские IMPION-шейдеры не исполняются; неоднозначное распределение нескольких материалов без групп геометрии пропускается с предупреждением.

В desktop-версии `.bin`, MTL и текстуры читаются из каталога открытой модели и вложенных каталогов. Сохраняйте относительные пути; внешние HTTP-ссылки и произвольные абсолютные ссылки не разрешены. Для текстур, явно указанных в одноимённом JSON модели, однозначные совпадения из ограниченного соседнего поиска подключаются автоматически; доступ выдаётся только к выбранным файлам. Остальные найденные изображения подключаются после подтверждения toast. Отсутствующие ресурсы показываются сообщением. OBJ использует первую указанную библиотеку MTL.

Текстуры также ищутся рядом с исходной моделью (в том числе `.blend`) и в папках `textures`/`maps`. Старые ссылки восстанавливаются по имени файла без учёта регистра, если совпадение единственное. Недостающие карты сопоставляются с именами материалов/мешей и суффиксами: `_basecolor`, `_albedo`, `_diffuse`, `_d`, `_normal`, `_n`, `_roughness`, `_metallic`, `_emissive`, `_ao`, `_alpha`. Неоднозначные наборы автоматически не назначаются.

PNG, JPG, WebP, BMP, GIF, PSD и TIFF можно перетащить на открытую модель. Выбранный в сцене объект служит целью; без выбора карты назначаются всем подходящим материалам. Для смены цели нажмите на другой меш; повторный клик в дереве или клик по пустому viewport снимает выбор. Можно одновременно перетащить модель, MTL/BIN и изображения. Меши без UV не получают текстуру автоматически.

PSD декодируется лениво через [ag-psd](https://github.com/Agamnentzar/ag-psd): используется сохранённое сводное изображение, слои и связанные smart-object-файлы не растеризуются. Для совместимости сохраняйте PSD с **Maximize Compatibility**. Неподдерживаемый или повреждённый PSD показывает ошибку и не меняет текущие материалы.

TIFF декодируется лениво штатным TIFFLoader/UTIF из Three.js. Не загрузившиеся карты отключаются, чтобы материал оставался видимым при освещении. `_mg` считается упакованной metallic/gloss-картой и автоматически не назначается: порядок её каналов зависит от исходного шейдера.

Браузерный `dev:web` поддерживает самодостаточные файлы и совместный drop ресурсов; поиск по соседним папкам и Blender обеспечивается Electron.

## Конвертация и экспорт

Нативное меню Electron заменяет верхнюю HTML-панель в установленном приложении.

- **Правый клик на пустом месте → Convert To…**: GLB/glTF с материалами, текстурами и поддерживаемыми анимациями; OBJ/STL/PLY — геометрия текущей позы, без текстур и анимаций.
- **Правый клик по мешу → Convert To…**: отдельный выбранный меш, включая текущую деформацию и мировую трансформацию; без скелета и анимационных клипов.
- **Правый клик → Convert To… → имя текстуры / All textures**: PNG, JPEG или WebP из поддерживаемых изображений, включая PSD/TIFF. JPEG сохраняется на белом фоне, прозрачность сохраняется в PNG/WebP. PSD использует composite, TIFF — первую страницу.
- Исходные файлы не меняются автоматически. Путь выбирается в системном диалоге сохранения. Отмена не создаёт файл.

glTF не воспроизводит все возможности материалов FBX/Blender; Lambert/Phong при экспорте приближаются стандартным PBR-материалом. Экспорт использует текущие отредактированные материалы независимо от режима просмотра. Пакет текстур сохраняется в новую подпапку, совпадающие имена получают суффиксы. FBX и BLEND доступны для импорта, но не как выходные форматы.

## Инструменты и редактор

Под плашкой статистики расположены Select, Move, Rotate и Scale. Move активен при запуске. В Select манипулятор скрыт. Во время перетаскивания манипулятора орбита камеры и анимация приостанавливаются; после отпускания восстанавливаются.

Выделение меша открывает Material под Animation: выбор слота материала, цвет, прозрачность, стороны, металлическость и шероховатость. В Textures доступны просмотр карты, цветовое пространство, оборачивание, повтор, смещение, центр, поворот и Flip Y. Правки материала и карты изолированы от других мешей, использовавших те же ресурсы. Изменения сохраняются через контекстный экспорт.

При загрузке дополнительно проверяются все непосредственные подпапки каталога модели, файлы родительского каталога и его непосредственные подпапки. Точные ссылки из JSON модели разрешаются до загрузки материалов, включая схему `assets/models` + `assets/textures`. Toast предлагает применить остальные найденные изображения. До Use textures они не загружаются; после подтверждения заполняются отсутствующие карты по ссылкам/именам. Более глубокого обхода нет. Dismiss оставляет материалы без изменений.

## Новые типы медиа

В `shared/mediaTypes.mjs` регистрируются семейства форматов, расширения и возможности. `MediaSession` выбирает адаптер с load/install/dispose/deactivate. Новому семейству нужен собственный адаптер и представление с data-media-view; панели с data-capability, меню, диалоги и команды получают доступные возможности из общего реестра. 3D-команды не активируются для неизвестного типа. Видео и изображения зарегистрированы как самостоятельные семейства документов.

Публичное имя и папка проекта — CationMedia. Технический appId и прежний профиль оставлены совместимыми с установленным просмотрщиком для обновления без потери настроек. Иконка: `public/icon.svg`, генерация многоразмерного ICO — `node scripts/icon.mjs`.

```powershell
npm run check
npm test
blender --background --factory-startup --disable-autoexec --python tests/create-fixtures.py -- artifacts/fixtures
npm run build

```

`node tests/workspace-smoke.mjs` проверяет исходники через временный Vite-сервер без production-сборки: выбор мешей, статистику, панели, обычные текстуры, PSD, совместный drop и справку Default apps. Для уже запущенного сервера задайте `VIEWER_TEST_URL`.

`node tests/context-menu-smoke.mjs` проверяет формирование контекстного меню по правому клику в viewport и дереве, его команды, режимы нормалей, восстановление, экспорт и сохранение панорамирования. По умолчанию native popup перехватывается тестом. `VIEWER_NATIVE_MENU_STRESS=1` включает показ и серию принудительных закрытий системного меню; в Electron 44.3 на этой машине такой режим нестабилен (`basic_string length_error`), что воспроизводится и в прежнем установленном просмотрщике.

`node tests/revision-smoke.mjs` проверяет новое меню, компоновку, проекции, экспорт моделей с повторным открытием, TIFF и конвертацию текстур. Необязательный `VIEWER_PKM` задаёт путь к исходному PKM FBX для регрессионной проверки. Тесты используют временный профиль.

Для проверки упакованного приложения задайте `VIEWER_EXECUTABLE` абсолютным путём к exe и повторите smoke-тест. Тестовые модели генерируются локально; каталоги `artifacts`, `release`, `dist` исключены из Git.

Архитектура опирается на [загрузчики Three.js](https://threejs.org/manual/en/loading-3d-models.html), [изоляцию Electron](https://www.electronjs.org/docs/latest/tutorial/context-isolation) и [fileAssociations electron-builder](https://www.electron.build/docs/api/electron-builder.interface.fileassociation/).
