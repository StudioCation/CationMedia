# Многослойное аудио и видеоредактор

## Аудиотаймлайн

При открытии аудио нижняя панель Timeline layers скрыта; кнопка со стрелкой на нижней границе раскрывает её, кнопка в самой панели сворачивает. Верхнюю границу можно тянуть мышью; с клавиатуры — сфокусировать разделитель и нажать стрелки вверх/вниз.

- Add layer добавляет дорожку (до 32). Один слой содержит не более одного блока. Блок перемещается по времени и на свободные дорожки. Масштаб задаётся Zoom; длинная композиция прокручивается горизонтально.
- Add audio / video открывает desktop-диалог нескольких файлов. Каждый импортируемый или перетаскиваемый файл получает новый слой. При сбросе на таймлайн позиция по времени берётся из точки сброса; при сбросе вне панели — с начала. Из видео берётся первая звуковая дорожка; отсутствие звука выводит ошибку.
- Выбор блока переключает верхнюю волну на этот клип. Существующие выделение, trim, delete, fades, эффекты и Undo/Redo относятся к выбранному клипу. История звуковых правок хранится отдельно для каждого клипа; перемещения/добавления слоёв не входят в эту историю.
- Транспорт расположен по центру единственной верхней панели и содержит громкость/Mute для прослушивания. При открытом таймлайне, нескольких блоках или обрезанном блоке воспроизводится композиция; выделение на верхней волне и выбранный loop сохраняют прослушивание выбранного звука. Play mix всегда воспроизводит композицию. Громкость прослушивания не влияет на экспорт.
- Курсор проходит через все слои; клик по линейке или пустому месту дорожки задаёт его время. Края блока обрезаются перетаскиванием и восстанавливаются обратным движением без изменения исходных сэмплов. Ctrl+D дублирует выбранный блок на новый слой, Ctrl+Shift+D разрезает по курсору и переносит правую часть на новый слой без сдвига по времени. Контекстное меню слоя содержит дублирование, разрезание и удаление слоя, включая последний. Верхняя волна остаётся редактором исходного звука выбранного блока.
- Save mix открывает существующий экспорт и по умолчанию сохраняет все клипы. Export selection only сохраняет выделение только выбранного клипа. Ctrl+S сохраняет всю композицию; для многоклипового монтажа открывается диалог выбора файла.
- Наложения суммируются; задержки дают тишину. Если сумма превышает 0 dB, весь результат нормализуется одним коэффициентом, чтобы избежать клиппинга. Частоты приводятся к частоте выбранного клипа; mono дублируется в выходные каналы, отсутствующие каналы многоканального источника остаются пустыми.

Сведение выполняется в worker. Совокупный объём импортируемого PCM и итоговый PCM ограничены 256 MB. Экспорт создаёт готовый аудиофайл; отдельный формат проекта со слоями пока не предусмотрен. Слои и их история живут в памяти до смены документа/закрытия приложения. Несохранённые изменения участвуют в существующем запросе сохранения.

## Видео

Главный экран содержит Video. Открытие доступно также через общий диалог, перетаскивание и аргумент командной строки.

Входные расширения: MP4, M4V, MOV, MKV, WebM, AVI, WMV, FLV, MPG/MPEG, TS/MTS/M2TS, OGV, 3GP, VOB, MXF. Реальное содержимое должно поддерживаться декодером включённой сборки FFmpeg.

Справа расположена скрываемая панель Edit settings: контейнер, кодек, качество/битрейт, FPS, ширина/высота, обрезка по четырём краям и fit/fill. Fit сохраняет всё обрезанное изображение с чёрными полями, fill заполняет кадр с дополнительной обрезкой. Предпросмотр показывает геометрию, а не артефакты будущего сжатия. Плеер имеет Play/Pause, Stop, перемотку и громкость; Space переключает воспроизведение, Ctrl+S открывает экспорт.

Выходные контейнеры: MP4, MOV, MKV, WebM, AVI, WMV, MPEG, TS, OGV. В зависимости от контейнера доступны H.264, H.265/HEVC, AV1, VP9, VP8, ProRes, MPEG-4, Motion JPEG, WMV 8, MPEG-2, Theora. Интерфейс ограничивает выбор совместимыми сочетаниями. ProRes использует профили Proxy/422/HQ по уровню качества; ручной битрейт для него отключён. MPEG-2 допускает стандартные частоты кадров; остальные ошибки конкретного кодека отображает FFmpeg.

Оценка размера: длительность × (целевой видеобитрейт + выбранный аудиобитрейт при включённом аудио) / 8 + 2,5% на контейнер. Для ProRes используется приближённая оценка от размеров, FPS и профиля. Это оценка, не гарантия; фактический размер выводится после экспорта. Звук экспортируется из первой дорожки; доступны битрейт 64–320 kbps, mono/stereo и частота 44,100/48,000 Hz (для Opus — 48,000 Hz). Можно выключить звук. Субтитры и дополнительные потоки не переносятся.

При несовместимости исходного видео с HTML-плеером FFmpeg создаёт временный H.264/AAC MP4 до 1280×720. Преобразование может занять время. Экспорт всегда читает оригинал, учитывает ориентацию/пропорции пикселя и выполняет crop → scale → fit/fill → FPS → encode. Источник не заменяется; результат сначала полностью кодируется во временный файл и затем копируется в выбранный путь. Таймаут обработки видео — один час, чтения метаданных — 30 секунд.

## Как обрабатываются медиа

Все вычисления локальные; файлы не загружаются на сервер.

- **Модели:** Three.js и штатные загрузчики GLTF/FBX/OBJ/STL/PLY/Collada/3DS разбирают сцену, геометрию, материалы и анимации. Draco, Meshopt, KTX2 обслуживают соответствующие сжатые ресурсы. Текстуры ищутся рядом и по sidecar-описаниям. BLEND конвертируется установленным Blender в GLB в фоновом процессе с отключённым autoexec. Рендер выполняется через WebGL. Эта обработка не менялась в данной доработке.
- **Аудио:** desktop FFmpeg декодирует в float32 PCM; волна, анализ и сведение используют workers. Web Audio воспроизводит PCM, FFmpeg применяет эффекты и кодирует финальный формат. В браузере используются доступные декодеры Web Audio; desktop-эффекты и экспорт там недоступны.
- **Видео:** FFmpeg читает метаданные и выполняет конвертацию. HTML video декодирует кадры/звук для просмотра, canvas показывает crop и fit/fill. Electron передаёт локальный файл потоком с byte-range запросами для перемотки. При необходимости создаётся совместимая временная копия. Экспорт кодируется отдельным FFmpeg-процессом без загрузки полного видео в renderer.

## Проверки

`npm run check` — синтаксис. `npm test` — существующие тесты и `tests/media-editors.test.mjs`: смещение/суммирование/ресемплирование аудио, нормализация, параметры видео, реальное кодирование всех предлагаемых сочетаний контейнер/кодек, извлечение аудио, совместимый preview, byte-range ответы.

Дополнительно проверен renderer-контракт сохранения через тестовую заглушку `exportAudio`: два клипа, один со сдвигом на 1 секунду, дали общий PCM длительностью 4 секунды / 48 kHz; запрос экспорта получил `overwrite: false`, документ стал сохранённым. Эта проверка не заменяет desktop IPC и реальный диалог сохранения.

Интерактивно проверены исходники в браузере: импорт звука из MP4, перенос между слоями, сдвиг по времени, выбор клипа, изменение высоты панели, воспроизведение микса, MP4-плеер, crop/fill, оценка размера, скрытие панели, размер окна 900×620. Скриншоты находятся в локальном `output/playwright`; в пакет они не входят. Полный smoke через Electron IPC не выполнен: запуск отдельного тестового Electron был отклонён автоматической проверкой разрешений. Исходная реализация затем собрана и установлена как 0.3.20. Последующая доработка UI описана в [media-ui.md](media-ui.md); она проверяется отдельно.

Единые контролы, визуальный crop, ползунки качества, автозапуск и меню: [media-ui.md](media-ui.md).

Проверка доработки таймлайна: реальные pointer-жесты crop, Ctrl+Shift+D, новые слои при импорте, движение/пауза курсора, gain=0.25, удаление всех слоёв и последующий импорт. Модульный тест сравнивает сведённые сэмплы до/после разрезания. Скриншоты 1440×960, 834×1112 и 390×844 находятся вне репозитория в `%TEMP%/cation-audio-*.png`. Это проверка исходников, не установленного пакета.
