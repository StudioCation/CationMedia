# Единый UI медиа

Основание: `README.md`, `docs/verification.md`, `docs/audio.md` и существующие `Controls.mjs`, `controls.css`, `PanelManager.mjs`. Язык UI — английский; поверхности плоские и тёмные, акцент mint, тонкие границы, Segoe UI. Изменение относится к аудио/видео; устройство 3D-представления сохраняется.

## Контролы и панели

- Команды используют Tabler через `toolButton`/`toolIcon`, компактные панели — `media-toolbar`, общие состояния hover, focus, pressed, disabled. Название документа остаётся в заголовке приложения. Внизу — состояние, время, свойства источника.
- Ползунок и числовое поле изменяют одно значение. Битрейт видео имеет логарифмический ползунок для удобной настройки небольших значений и точное поле kbps. Качество 0–100% задаёт целевой битрейт с учётом размера и FPS, а не обещает процент сохранённых деталей. Для ProRes качество выбирает профиль Proxy/422/HQ.
- Правый инспектор видео прокручивает только содержимое; оценка размера и экспорт остаются доступны внизу. Его можно скрыть кнопкой, размер меняется границей. На узком экране панель работает как раскрываемая поверх плеера.
- Размеры инспектора и аудиотаймлайна сохраняются локально. Клавиши стрелок на разделителе меняют размер, Home/двойной клик возвращают исходный. Инспектор скрыт при запуске и открытии каждого видео.
- Аудиотаймлайн использует такие же иконки и ползунки. Выбранный клип указан рядом с командами. Play/Pause mix останавливает и продолжает с текущей позиции; Stop возвращает микс к началу. Редактирование/смена клипа останавливает микс.

## Видео

- Открытое видео автоматически начинает воспроизведение, включая открытие совместимой копии после FFmpeg. Уход из документа, Stop и экспорт отменяют ожидающий автозапуск. Если браузер запрещает звук без жеста пользователя, показывается предложение нажать Play; desktop использует настроенную политику autoplay.
- В режиме crop показывается исходный кадр, затемнение удаляемой области, сетка и восемь маркеров. Маркеры меняют границы, внутренняя область перемещает рамку. Координаты полей и ползунков синхронизированы с рамкой и ограничены исходным кадром. Стрелки на рамке/маркере меняют координату на 1 px, Shift — на 10 px. Done возвращает предпросмотр результата с fit/fill. Reset crop обнуляет обрезку.
- Громкость/выключение звука относятся к прослушиванию. Include audio, Audio quality (64–320 kbps), Sample rate (44,100/48,000 Hz), Mono/Stereo относятся к выходному файлу. Opus использует 48,000 Hz. Эти настройки передаются в FFmpeg, аудиобитрейт учитывается в оценке размера.
- Space — Play/Pause, Esc — Stop, Home — начало, L — Loop, Left/Right — ±5 секунд. Поля и кнопки сохраняют штатное клавиатурное управление; Ctrl+S работает и при фокусе в поле.

## Аудиоэкспорт

Существующие уровни Standard/High/Maximum получили ползунок с явной характеристикой качества. Для MP3/AAC/M4A/Opus/WMA/AC3 доступен отдельный ползунок и точное значение битрейта; значение проверяется кодеком. WAV/AIFF/FLAC используют разрядность из пресета, OGG — уровень Vorbis. Изменение пресета сбрасывает ручной битрейт к соответствующему значению.

## Меню

Шаблон нативного меню строится по текущему семейству в `shared/mediaMenu.mjs`. `Load 3D demo` доступен только на стартовом экране и в 3D. Аудио и видео не получают команды моделей, Blender или shading. Видео имеет собственные Playback, View → Video settings/Visual crop и контекстное меню с Convert To для всех поддерживаемых выходных контейнеров. Save frame as PNG сохраняет кадр через FFmpeg из оригинала с текущими crop, размером и fit/fill. Кнопки видеопанели объединены по центру; кнопка скачивания удалена. Неизвестные типы не направляются в меню мешей.
